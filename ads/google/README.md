# Taxi and Fly — Google Ads video

Έτοιμο κάθετο βίντεο 9:16 (1080×1920, ~43"), χωρίς TTS. Μόνο μουσική κλίνη — η αφήγηση θα μπει από ηχογράφηση του ιδιοκτήτη.

- `taxi-and-fly-google-ads-9x16.mp4` — εικόνα + μουσική, χωρίς φωνή
- `spikazma-el.txt` — τα λόγια για ηχογράφηση
- `voiceover-el.txt` — ο ίδιος διάλογος με σημείωση εικόνας
- `stills/` — καρέ AI ηθοποιών
- `build_video.py` — ξαναχτίζει το σποτ
