# Βάρδια

Πρόγραμμα για οδηγό που δουλεύει **Bolt**, **Uber** και **FreeNow** την ίδια μέρα.

Καταγράφεις τι ώρα έφυγες από κάθε εφαρμογή και πόσα νούμερα πήρες. Αν στο Uber είχες 10 νούμερα και κόλλησες, το σημειώνεις. Η εφαρμογή βγάζει μέσο όρο για την επόμενη ίδια μέρα και σου λέει μέχρι τι ώρα αξίζει να πάρεις νούμερο, ώστε να είσαι ακριβής στο χρόνο.

## Τι κάνει

- **Σήμερα:** ώρα που άνοιξες, ώρα που έφυγες, νούμερα, «κόλλησε».
- **Αύριο:** μέσος όρος ώρας αναχώρησης ανά εφαρμογή, μέσος αριθμός νούμερων, τελευταία ώρα για νούμερο.
- **Παίρνω νούμερο τώρα;** αν το τρέχον νούμερο σε πάει μετά την συνηθισμένη ώρα εξόδου, σου λέει να αλλάξεις εφαρμογή.
- **Εβδομάδα:** όλες οι μέρες δίπλα στον μέσο όρο της ίδιας ημέρας.
- **Ιστορικό:** διόρθωση, αντίγραφο ασφαλείας, παράδειγμα 3 εβδομάδων.

Τα δεδομένα μένουν στη συσκευή (localStorage). Δεν στέλνονται πουθενά.

## Τρέξιμο

```bash
npm install
npm test
npm run dev
```

Άνοιγμα στο κινητό στο ίδιο δίκτυο, από τη διεύθυνση που δείχνει το Vite. Μπορείς να την προσθέσεις στην αρχική οθόνη.

```bash
npm run build
npm run preview
```

Ο μέσος όρος χρησιμοποιεί ρολόι βάρδιας από το μεσημέρι, ώστε το `00:00` του FreeNow να μετράει μετά τις `21:30` του Uber και όχι ως αρχή της ημέρας.
