# Taxi and Fly — Google Ads landings

Static landing pages for **Taxi and Fly** (Athens airport taxi) that are safe for Google Ads Final URLs: no store auto-redirects, no slashless 301s, visible business contact + privacy.

## Quick start

1. Merge this PR.
2. Enable **GitHub Pages** on this repo (`Settings → Pages → Deploy from branch main / root`).
3. Set Google Ads **Final URL** to:
   `https://taxiapp2026.github.io/TAXIdriverApp/ads.html`
4. Request review.

Full checklist (Greek): [GOOGLE_ADS.md](./GOOGLE_ADS.md)

To update the existing live site at `taxi-client-app`, copy files from [`deploy-to-taxi-client-app/`](./deploy-to-taxi-client-app/).
